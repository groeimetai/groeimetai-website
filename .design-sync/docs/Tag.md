A small mono chip in accent orange on a tinted background — the categorising
label of the design system. Used for the pillar numbers, topic labels on
training cards, and the technique labels in the agent anatomy.

## Usage

```jsx
<Tag>FOLDERS</Tag>
<Tag>01 / INSTRUCTIES</Tag>
```

Uppercase, one or two words, no punctuation beyond the `/` separator used in
numbered pairs. Tags do not carry state and are never interactive — a clickable
filter is a button, not a Tag.
